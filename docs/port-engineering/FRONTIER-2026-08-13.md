## Profile-authoring recipe (used for ceil and fxaa)

1. Probe the blocker. 2. Compute fingerprints from the live IR with the
   profile module's own `_sha`/`_span`/`_whole_program_fingerprint` helpers.
3. Write a dict-keyed profile with a whole-program census that matches the
   authorized set EXACTLY (an extra site anywhere is a hard failure).
4. Wire BOTH authorities independently — validator and emitter.
5. Add the builtin to the node-identity skip-list so `used.add` is never called
   and the frozen 44-entry vocabulary is untouched.
6. Slice-row key-set, drift list, define-contract map, row-to-validator threading.
7. Runtime function + emitter lowering. 8. Catalog test count/name/list.

**Check the narrowing semantics per builtin.** `round` needs a shim because the
reference is `Math.round` (half-toward-+inf, matching neither the GLSL spec nor
`std::round`). `ceil` needs none — `Math.ceil` and `std::ceil` agree on every
finite double. Copying a profile wholesale imports the wrong answer.

## The counted-for bucket, named (12 programs)

The single biggest lever left. All blocked on `unsupported counted-for program
proof`:

`classicNoisedeck/noise`, `filter/blur:blurH`, `filter/blur:blurV`,

`filter/normalize:statsFinal`, `filter/parallax`, `filter/tetraColorArray`,
`synth/mandelbrot`, `synth/noise`, `synth/testPattern`

Known per-program facts, so nobody re-derives them:

- **`blurH` / `blurV` / `statsFinal` / `tetraColorArray`** need loop bounds
  derived from a runtime uniform or an unbounded texture size — a mechanism that
  does not exist yet. This is the shared unlock for four of the twelve.
- **`lightLeak`** additionally needs `out`-parameter admission (gates 3 programs
  total, with `watercolor` and `mandelbrot`).
- **`parallax`** additionally needs `textureLod` (gates only this program).
- **`mandelbrot`** needs TWO mechanisms: loop-bound widening AND `out`-parameter
  admission.
- **`median`** uses a `while`-based quickselect that is not soundly provable
  statically, and its canonical JS factory crashes at 5x5 (see DEFECTS-FOUND.md).
  Its oracle targets the working adapter twin.
- **`dither`** is blocked upstream: the error-diffusion path throws
  unconditionally in the reference. Not portable until that is fixed.

Oracles already exist for most of these under `loopproof/oracle-a/` and
`loopproof/oracle-b/`, with per-program evidence that a trip-count mutation
genuinely diverges.
