## Confirmed root cause

Canonical JavaScript Lens line 4470 conditions on a newly constructed
`PooledFloat32Array([color[0] == 1, color[1] == 1, color[2] == 1])`. A typed
array object is always truthy in JavaScript, so the expression always returns
the existing color and its tint alternative is unreachable. Generated C++
evaluates vector equality as a scalar boolean and applies the tint alternative
when the vector is not all ones.
